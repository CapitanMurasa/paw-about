About this project

Perfect Audio Works is an open source lightweight and cross platform audio player! It uses C++, Qt Framework, PortAudio (with optional mpg123, sndfile and FFmpeg) and more stuff that doesn't need any introduction, but if you're curious you can look somewhere below, i would write about every library that this program uses.

Why did i create this program?

It's as simple as that. I just wanted to create a decent alternative to winamp, but also add some things that i'd like add from self, e.g. Plugin support trough Python, native flac processing (because winamp at that time needed a separate plugin that was so hard to find across the internet) and linux support! It all begun from a simple experiment with Portaudio and libsndfile to create a loopback that would feed raw PCM bytes from sndfile to portaudio, and i was so excited with that experiment that it grew into what we have today by gradually integrating Qt framework, going trough treading and race condition hell and alot of memory leaks and segfaults (i'm not a good programmer y'know).
